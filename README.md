## BlueGram

Backend веб-приложения социальной платформы с постами, комментариями и системой лайков.

---

## Описание

**BlueGram** — это pet-проект, в котором реализована серверная часть социальной сети.
Основной фокус — архитектура backend-приложения, работа с базой данных, аутентификация и оптимизация запросов.

Проект написан с использованием асинхронного стека и разделён на слои (repository/service), что приближает его к production-подходу.

---

## Технологии

* Python 3
* FastAPI
* PostgreSQL
* SQLAlchemy (async)
* Pydantic
* JWT (access + refresh)
* asyncio
* Alembic
* Docker

---

## Основной функционал

### Аутентификация

* JWT access/refresh токены
* Хранение refresh токенов в БД
* Logout с инвалидированием токенов
* Работа с cookies

### Посты

* Создание, редактирование, удаление постов
* Получение списка постов (лента)
* Пагинация (limit / offset)
* Подсчёт лайков и комментариев

### Комментарии

* CRUD для комментариев
* Получение комментариев поста
* Пагинация

### Лайки

* Лайки для постов и комментариев
* Toggle (лайк / анлайк)
* Получение списка пользователей, поставивших лайк

## Архитектура

```
src/
├── api/            # роутеры (FastAPI endpoints)
├── database/       # инициализация БД и управление соединениями
├── models/         # ORM модели
├── repositories/   # работа с БД через запросы
├── services/       # бизнес-логика
```

### Используемые подходы:

* Repository Pattern
* Service Layer
* Unit of Work
* Dependency Injection

---

## Работа с базой данных

* Асинхронный SQLAlchemy
* Оптимизация запросов
* Использование счётчиков (likes_count, comments_count)

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/hankpew/bluegram.git
cd bluegram
```

### 2. Создать .env файл

```PowerShell
cp .env.example .env   # Linux/macOS
copy .env.example .env # Windows
```
При необходимости измените значения переменных внутри .env.

### 3. Запустить проект через Docker

```bash
docker compose up --build
```
